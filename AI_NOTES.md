# AI_NOTES

## Инструменты и запросы

Использовал ChatGPT Codex, чтобы изучить проект, провести ревью и доработать API бронирования. Для проверки использовал Docker Compose, Artisan, PHPUnit и Laravel Pint; сверял Laravel 13 API с официальной документацией.

Ключевые запросы дословно:

1. «проверь, почему не запускается контейнер demo-booking-app-1\»
2. «сделай Часть 1. Ревью»
3. «сделай Часть 2. Доработка»

## Что ИИ предложил неоптимально и как это проверил

Для Adminer я сначала предложил опубликовать веб-интерфейс на порту 8080. Команда Docker показала, что порт уже занят другим контейнером. Я проверил опубликованные порты через `docker ps` и перезапустил Adminer на свободном порту 8081.

## Что проверил вручную

- Сверил правила задания с маршрутами, контроллером, моделями, миграциями и фабриками, прежде чем менять код.
- Проверил фактические логи остановившегося контейнера: Composer завершался с `curl error 28` при загрузке пакетов с GitHub. PostgreSQL при этом был healthy.
- Проверил сценарии создания и отмены брони feature-тестами, включая пересечения, границы рабочего дня, часовые пояса, пользователя-автора и ошибки валидации.
- После изменений запустил весь набор тестов и Pint: 19 тестов и 64 проверки прошли, форматирование прошло.

Я не полагался только на сгенерированные объяснения: сверял вывод команд и тестов с ожидаемым поведением из задания. Дополнительно проверил защиту от параллельного создания брони: блокировка строки комнаты находится внутри транзакции, перед проверкой конфликтов.
